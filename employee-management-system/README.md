# Employee Management System

A full-stack Employee Management System built to manage employee records through a modern web interface.

## Features

- View all employees
- Add new employees
- Edit employee details
- Delete employees
- Search employees
- Dashboard with employee statistics
- Data stored in MySQL database
- REST API built with Flask
- Responsive React frontend

## Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- HTML5
- CSS3

### Backend
- Python
- Flask
- Flask-CORS

### Database
- MySQL

### Tools
- Git
- GitHub
- Visual Studio Code
