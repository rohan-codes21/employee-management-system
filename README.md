# Employee Management System

A full-stack Employee Management System built with React, Flask, and MySQL.

The application allows users to manage employee records through a modern web interface with complete CRUD functionality.

## Features

- View all employees
- Add new employees
- Edit employee details
- Delete employees
- Search employees
- Dashboard interface
- REST API backend
- MySQL database integration
- Secure database credentials using environment variables

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Vite

### Backend
- Python
- Flask
- Flask-CORS

### Database
- MySQL
